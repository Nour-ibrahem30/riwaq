# رِواق — Riwaq

مكتبة عربية بواجهة داكنة ثابتة، مسارات قراءة ومقارنات، بحث، وحفظ التقدّم. React + Vite + Motion + React Flow + Capacitor + PDF.js.

## المعمارية

مشروع واحد بواجهة ومنطق قراءة مشتركين في `src/`، ومشروعي Android وiOS في `android/` و`ios/`. فصل نسخة مستقلة كان سيكرر الواجهة والتقدّم والتعديلات. طبقة الموبايل تستخدم قارئ PDF وحفظ نسخ المستخدم في IndexedDB على الجهاز، بينما خادم الكمبيوتر يفتح الملفات من مجلد محلي محصور بقائمة الكتب. لا توجد خدمة سحابية أو مزامنة حسابات.

## تشغيل الويب

يتطلب Node.js 24. شغّل `npm ci` ثم `npm run build` ثم `npm start`، وافتح http://127.0.0.1:4173 . على Windows يمكنك استخدام `Start.cmd` بعد البناء.

ضع مسار مكتبتك في ملف `riwaq.local.json` غير مرفوع للمستودع:

```json
{"libraryRoot":"C:/Books"}
```

أو اضبط المتغير `RIWAQ_LIBRARY_DIR`. مسارات الكتب داخل `src/library.json` نسبية لهذا المجلد، بنفس أسماء الملفات والمجلدات. الملفات الأصلية PDF ليست مرفوعة. صفحة HTML المفتوحة مباشرة تعتمد على تشغيل خادم الكمبيوتر لزر فتح الكتاب؛ زر «اقرأ نسخة من جهازك» يعمل باختيار ملف محلي.

## الموبايل

`npm run mobile:sync` يبني الواجهة وينسخها للمشروعين. `npm run android` يفتح Android Studio، و`npm run ios` يفتح Xcode على Mac. Android يحتاج Android Studio وSDK 36 وJava 21، وiOS يحتاج Mac وXcode متوافقًا مع Capacitor 8.

الفهرس والأغلفة والمسارات متاحة دون إنترنت. افتح كتابًا واختر نسخة PDF من ملفات هاتفك مرة واحدة؛ يحفظ التطبيق النسخة محليًا ويعرض صفحاتها داخله. هذه الملفات لا تدخل المستودع. مسح بيانات التطبيق يحذف النسخ المحفوظة والتقدّم؛ احتفظ بأصل الكتاب وصدّر تقدّمك دوريًا. لا يتم تنزيل الكتب تلقائيًا على الهاتف أو الوصول إلى قرص الكمبيوتر منه.

GitHub Actions يبني APK تجريبيًا قابلًا للتثبيت على Android، ونسخة iOS للمحاكي. النسخة التجريبية ليست إصدار متجر. تثبيت iOS على هاتف فعلي ونشر المتاجر يحتاجان شهادات وتوقيع وحسابات المطوّر.

## البيانات والتقدّم

الفهرس الحالي يضم 103 كتب و16 مسارًا و6 مقارنات؛ «كل رجال الباشا» اقتراح غير منزّل. الترتيب للمقارنة والتدرّج، وليس حكمًا نهائيًا على دقة كل مصدر. تعديل الفهرس يتطلب تحديث `src/library.json` وإعادة البناء.

التقدّم والمفضلة محفوظان في المتصفح أو التطبيق، ويختلفان بين الأجهزة والعناوين. استخدم تصدير/استيراد التقدّم للنقل اليدوي. الخطوط محلية وتراخيصها في `licenses/`؛ أغلفة الكتب وحقوق المؤلفات لأصحابها.

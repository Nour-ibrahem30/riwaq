# رِواق 2 — Riwaq

تطبيق قراءة عربي داكن للويب وAndroid وiOS. الفهرس الحي من Supabase Postgres، وملفات الكتب من Supabase Storage. القراءة مباشرة بدون حساب أو اختيار PDF من الجهاز.

## التشغيل

Node.js 24: `npm ci` ثم `npm run build` ثم `npm start`. للتطوير `npm run dev`. الموقع: https://riwaq-wheat.vercel.app . أحدث APK في GitHub Releases.

## المعمارية

- `src/ReadingApp.jsx`: الرفوف، البحث، المفضلة، التفاصيل، المسارات والمقارنات. الواجهة مشتركة بين الويب والموبايل.
- `src/cloud.js`: قراءة جدولي `riwaq_tracks` و`riwaq_books` مباشرة. لا يستورد فهرس كتب ثابتًا. المفتاح في `cloud-config.json` publishable ومسموح وجوده في العميل.
- `src/Reader.jsx`: يبدأ فتح الكتاب تلقائيًا، يجمع الأجزاء ويتحقق من SHA-256، يعرض PDF.js محليًا، ويحفظ الصفحة والتكبير.
- `src/cache.js`: IndexedDB للفهرس ونسخ PDF. نسخة محفوظة للفهرس عند انقطاع الاتصال. تغيير بصمة الكتاب في قاعدة البيانات يبطل نسخة PDF القديمة عند إعادة فتحه.
- `seed/`: نسخة أولية لاستيراد البيانات فقط، وليست مصدر بيانات التطبيق وقت التشغيل.
- `android/` و`ios/`: حاويتان Capacitor لنفس الواجهة؛ `npm run mobile:sync` يبني وينسخ الواجهة إليهما.

الفهرس يحدث من قاعدة البيانات عند فتح التطبيق أو زر التحديث. إضافة كتاب أو تعديل ترتيبه أو وصفه من Table Editor لا تتطلب إعادة بناء التطبيق. `track_id` يربط الكتاب بالمسار، و`position` يحدد الترتيب. `parts` تحتوي مسارات الأجزاء وأحجامها وبصماتها؛ الحد الحالي 16 MiB للجزء. الكتب المقترحة تستخدم `pending=true` مع رابط ناشر HTTPS.

## الصلاحيات

القراءة عامة للكتالوج وملفات الكتب المدرجة فيه، بناءً على موافقة المالك. لا يحتاج القارئ إلى Supabase Auth. الكتابة على جداول الفهرس ممنوعة عن anon وauthenticated، والتعديل يتم من لوحة إدارة Supabase أو مفتاح خدمة على خادم موثوق فقط. سياسة Storage العامة تسمح بقراءة الأجزاء الموجودة فعلًا في الفهرس فقط؛ لا تمنح رفعًا أو تعديلًا أو حذفًا. مفاتيح الخدمة وبيانات الدخول ليست ضمن الكود أو APK.

## القراءة والتقدّم

أول فتح للكتاب يحتاج اتصالًا لتنزيل أجزائه؛ بعدها يحتفظ التطبيق بنسخة محلية إذا سمحت المساحة. ملفات PDF الأصلية لا تدخل GitHub أو APK. الفهرس والأغلفة يتوفران دون اتصال بعد أول تحميل، وتطبيق الموبايل يحتوي الواجهة داخله. صفحة الويب تحتاج تحميل الواجهة أولًا؛ لا يوجد Service Worker يتيح إقلاع الموقع كاملًا دون شبكة.

التقدّم والمحفوظات محلية على الجهاز، مع استيراد وتصدير يدويين من صفحة المحفوظات؛ لا توجد مزامنة حسابات. بيانات الإنجاز والمفضلة من النسخ السابقة محفوظة بنفس المفاتيح. ملفات الكتب القديمة المحفوظة في IndexedDB تقبل بعد التحقق من بصمتها. حذف بيانات التطبيق يمسح النسخ والتقدّم المحلي.

## بناء الموبايل

Android: Android Studio، SDK 36 وJava 21. iOS: Mac وXcode متوافق مع Capacitor 8. أو استخدم GitHub Actions الذي يبني APK تجريبيًا ونسخة iOS للمحاكي. تثبيت iOS على جهاز فعلي ونشر المتاجر يحتاجان توقيعًا وحسابات Apple/Google.

الخطوط محلية وتراخيصها في `licenses/`. حقوق الكتب وأغلفتها لأصحابها. ترتيب القراءة يساعد المقارنة والتدرّج ولا يمثل حكمًا على دقة كل مصدر.
